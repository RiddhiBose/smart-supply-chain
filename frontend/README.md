# Smart Logistics System - Premium Frontend

A cutting-edge, production-ready logistics management platform with a stunning premium UI design. Built with React, TypeScript, and modern web technologies.

## 🚀 Features

### Premium Design System
- **Modern Gradients**: Smooth, professional gradients throughout the interface
- **Glassmorphism Effects**: Sophisticated backdrop blur and transparency effects
- **Advanced Animations**: Smooth micro-interactions using Framer Motion
- **Premium Typography**: Clean, modern font hierarchy with Inter font family
- **Responsive Design**: Fully responsive across all devices with mobile-first approach

### Core Functionality
- **Real-time Tracking**: Live location updates and delivery estimates
- **Route Optimization**: AI-powered route planning and traffic analysis
- **Weather Integration**: Real-time weather data for delivery scheduling
- **Delay Prediction**: Advanced algorithms for proactive delay management
- **Dual Portals**: Separate customer and employee interfaces
- **Smart Reassignment**: Automatic order distribution based on availability

### UI/UX Highlights
- **Hero Section**: Eye-catching animated hero with floating elements
- **Feature Cards**: Interactive cards with hover effects and gradient icons
- **Statistics Section**: Animated counters with premium styling
- **CTA Sections**: Compelling call-to-action areas with gradient buttons
- **Premium Navigation**: Glassmorphism header with smooth scroll effects
- **Newsletter Signup**: Modern footer with interactive subscription form

## 🛠️ Technology Stack

- **Frontend**: React 18.2.0 with TypeScript
- **Styling**: TailwindCSS 3.4.0 with custom design system
- **Animations**: Framer Motion 10.16.0
- **Icons**: Lucide React 0.294.0
- **Routing**: React Router DOM 6.8.0
- **Maps**: Leaflet 1.9.0 with React Leaflet 4.2.0
- **HTTP Client**: Axios 1.3.0
- **Build Tool**: Create React App with TypeScript

## 📦 Installation

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd windsurf-project-2/frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

### Alternative Setup (Windows)
If you're on Windows and encounter PowerShell execution policy issues, run:
```bash
# Run the provided batch file
./install-and-start.bat
```
